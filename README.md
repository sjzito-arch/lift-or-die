# Lift or Die Project Kit v2.0

This kit is the starting point for building the personal Lift or Die iPhone PWA with Claude Code.

Start here:

1. Read `docs/Build-Guide.md`.
2. Open this folder in Claude Code.
3. Use the first prompt in `docs/Prompt-Library.md`.
4. Build one slice at a time.

The detailed product behavior lives in `docs/Product-Spec-v1.0.md`. Claude's standing instructions live in `CLAUDE.md`.
